Pokémon Guessing Browser Source

Open this source with URL parameters to connect it to chat and tune how each round behaves.

URL options

  • ?channel=YourTwitchName – required. Connects the overlay to that Twitch channel's chat.
  • &clues=6 – total number of clue panels shown each round. Default: 6.
  • &totaltime=45 – full round length in seconds. Default: 45.
  • &interval=5 – time in seconds between clue reveals. Default: 5.
  • &reveal=7 – how many seconds before round end the Pokémon image starts revealing. By default it uses about half the round.
  • &sync=0 – delay before the round really gets going. Useful when you want stream and browser source to line up. Default: 0.
  • &synctime=0 – legacy alias for sync. Use either one, but sync is preferred.
  • &autostart=10 – seconds to wait after a round ends before the next one starts automatically. Default: 0 (manual / no auto-start).
  • &mods=user1,user2 – comma-separated Twitch usernames allowed to use the moderator-only round skip command.
  • &debug=true – shows the on-screen debug log and browser console messages. Default: false.

Chat behavior

  • Viewers guess by typing the Pokémon name in Twitch chat.
  • Messages starting with ! are ignored, so normal bot commands do not count as guesses.
  • nextpoke starts the next round immediately.
  • Only the streamer in channel and usernames listed in mods can use nextpoke.

Example

https://yourname.github.io/poke-game/?channel=yourchannel&clues=6&totaltime=45&interval=5&reveal=7&sync=0&autostart=10&mods=modone,modtwo&debug=true
